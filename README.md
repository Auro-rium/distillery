# Distillery

Sandbox-verified distillation autopilot on Nebius Token Factory. An agent (Nemotron 3 Ultra/Super/Nano) turns a
narrow, repetitive big-model task into a small fine-tuned model, with every training example and every evaluation
executed and verified in Token Factory Sandboxes.

**Status:** Phase 0 (API spikes). Nothing here has produced results yet; see [STATUS.md](STATUS.md).
